# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be kind. Disagree with ideas, not people.
- Be specific. "This number is wrong because…" beats "this is bad."
- Assume good faith. Most contributors and maintainers are doing their best with limited context.

## Scope

Applies to all project spaces: GitHub issues, PRs, discussions, and any associated chat (e.g. when Envisioning hosts an open conversation about the benchmark).

## Reporting

If you encounter behavior that violates this code, email **hi@envisioning.com**. Reports stay confidential. We'll respond within 7 days.

## Enforcement

Maintainers may remove comments, close issues, or block users at their discretion when this code is violated. We aim to be transparent about why.
